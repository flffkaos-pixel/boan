## Foundations (기초) 프로젝트

> [!NOTE]
> **처음 코딩을 시작하신다면 여기부터** 시작하세요. Python을 처음 접하거나 터미널이 낯선 분들을 위해 설계되었습니다. 소스 파일은 풍부한 주석과 함께, 모든 `learn/` 폴더가 개념을 zero부터 설명합니다.

| 프로젝트 | 배울 내용 |
|---------|----------|
| **해시 식별자** | 해시 계열 (MD5, SHA, bcrypt, Argon2) • PHC 문자열 형식 • 패턴 매칭 • 순수 함수 설계 |
| **HTTP 헤더 스캐너** | HTTP 기초 • 보안 헤더 (CSP, HSTS, X‑Frame‑Options) • httpx 요청 • 점수 감사 |
| **비밀번호 관리자** | Argon2id 키 도출 • AES‑GCM 인증 암호화 • 보안 디스크 보관함 • 마스터 비밀번호 워크플로 |

| **간단한 취약점 스캐너** | CVE 데이터베이스 • 종속성 스캔 • 취약점 평가 |
| **네트워크 트래픽 분석기** | 패킷 캡처 • 프로토콜 분석 • 트래픽 시각화 |

| **기본 C2 비컨** | C2 아키텍처 • MITRE ATT&CK • WebSocket • XOR 인코딩 |

| **Systemd 영속성 스캐너** | 영속성 기법 • Systemd 내부 • Cron 분석 • 위협 헌팅 |
| **Linux eBPF 보안 트레이서** | eBPF 프로그램 • syscall 추적 • BCC 프레임워크 |
| **트로이안 애플리케이션 빌더** | 트로이안 구조 • 데이터 유출 • 파일 암호화 • 공격 수명주기 |

| **방화벽 규칙 엔진** | 방화벽 내부 • 규칙 파싱 • iptables/nftables • V 언어 |
